How it works

  1. Poster locks OKB in the ChipJobs escrow with a spec hash, a target processor and a deadline.
  2. Designer builds the circuit on tapeout.net using an existing TapeOut processor and tapes it out (the circuit NFT lands in their wallet).
  3. Designer calls submitAndClaim(bounty, cpu, circuitId); the contract checks factory.cpuAt(cpu) + ownerOf(circuitId) == designer and pays instantly.
  4. No valid claim before the deadline? The poster is refunded in full.
